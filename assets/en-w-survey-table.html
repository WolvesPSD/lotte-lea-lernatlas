Use this table only for the six made-up votes in the learning task. The download has category names and empty tally and number cells. It contains no answers, names or real survey results.

Download blank CSV table

Open in Excel or Calc

  1. Open the saved CSV. If you see an import window, choose UTF-8 and semicolon as the separator.
  2. Check that Choice, Tally marks and Number of votes are three separate columns.
  3. Count each fictional slip once, then enter tally marks and totals in its choice row. Check the overall total yourself.

CSV files may not keep formatting or formulas when saved. Save your edited copy as XLSX or ODS if you want to keep those. You can also fill the table on paper; using a program is optional and is only confirmed if someone actually sees the steps.
